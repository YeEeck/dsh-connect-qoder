# 03: 排队耐心花完时的失败文案

**P2 · 规模 S · 依赖 无**

**Status:** ready-for-agent
**Category:** enhancement

## What to build

排队耐心花完时，用户看到的错误要说清楚三件事：Qoder 一直在排队、已经等了多少秒、重发会重新计时。

现在的文案只说"Qoder is busy — the request was queued"，用户无法判断重发是有意义的还是会再白等
一轮。而 0.7.4 收窄宿主重试集合之后，这份耐心就是唯一的耐心——用户更需要知道自己花了多少。

**与空闲窗口的失败区分开**：空闲窗口到期说的是"上游多久没有输出内容"，不是排队，两者不共用
一句文案。

## Blocked by

None (can start immediately).

## Acceptance criteria

- [ ] 排队耐心花完的错误文案包含已等待的时长
- [ ] 该文案说明重发会重新计时
- [ ] 空闲窗口到期走的是另一条文案，措辞不涉及排队
- [ ] 文案在中英两套语言里都存在且语义一致
- [ ] 状态码仍是可重试的那一档，不因为文案改动而改变宿主的行为
